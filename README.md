# React Project Manager (v2 - Context API)

A **project and task management app** built with **React**, refactored to use **Context API** for centralized state management and to solve prop drilling issues.

## Features

- Manage multiple projects and tasks
- Add, edit, and delete tasks and projects
- Centralized state with **Context API**
- Immutable state updates for predictable UI
- Responsive UI with **Tailwind CSS**

## Tech Stack

- React.js, Context API
- Tailwind CSS
- JavaScript ES6+, HTML5, CSS3
