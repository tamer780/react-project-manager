## React Project Manager

A simple project and task management application built with React.

### Features
- Create and delete projects
- Add and remove tasks per project
- Clear separation between project and task state
- Clean component structure

### Focus Areas
- State lifting and centralized state management
- Immutable state updates
- Component responsibility and data flow
- Conditional rendering

### Tech Stack
- React
- JavaScript (ES6+)
- Tailwind CSS
